# Architecture

## Goal

The data plane (gateway) is designed so that a properly deployed fleet can reach
**99.99% availability on the request path**: about 4 minutes 23 seconds of
downtime per month. The control plane only needs 99.9%, because the gateway does
not depend on it to serve traffic.

An open-source project does not have an SLA; a deployment does. What this
repository commits to is a design and a reference topology that make that
target reachable, and tests that demonstrate the failure behaviour.

**SLI.** The share of valid requests to `/v1/*` and `/proxy/*` answered without
an error attributable to Stratum (5xx generated by the gateway, gateway
timeouts, rejections caused by an internal dependency), measured at the load
balancer. Errors returned by the provider and passed through are measured
separately (`reason="upstream_status"` in `stratum_requests_total`).

Two consequences of the arithmetic:

- Availabilities multiply in series (99.99% × 99.99% = 99.98%), so everything on
  the request path must be redundant or better than the target.
- Public LLM APIs typically publish SLAs around 99.9%. End-to-end 99.99% needs
  failover to an *equivalent deployment of the same model* (for example the same
  model on two clouds), not a different model.

## Static stability

Nothing except the LLM provider is allowed on the synchronous request path.

| If this fails | The gateway |
|---|---|
| Control plane or its database | Keeps serving the last good snapshot, indefinitely (ADR-0005). Staleness is exported as a metric. |
| Redis / shared quota store | Unaffected for auth and policy (in memory). Quotas fall back to local counters (ADR-0004). |
| Telemetry backend | Unaffected. |
| One replica / one zone | The load balancer removes it via `/readyz`; peers absorb the load. |
| A deploy | Readiness fails first, then in-flight streams finish before the process exits. |
| The LLM provider | Returns a fast, explicit error. Failover between equivalent deployments is on the roadmap. |

## Request path

```
client ──► /v1/* or /proxy/{provider}/*
            1. auth      SHA-256(key) → snapshot map lookup
            2. route     provider from path, "provider/model", or policy
            3. policy    team policy: disabled? provider? model?
            4. quota     monthly tokens (local counters)
            5. content   PII (pii_action) and secrets (dlp_action): block / redact / log
            6. forward   provider credentials injected; client key never forwarded
            7. stream    bytes passed through as they arrive; usage parsed on the side
```

Timeouts are per phase: connect 5 s, TLS 5 s, first byte
`STRATUM_UPSTREAM_HEADER_TIMEOUT`, and an idle watchdog between streamed chunks
(`STRATUM_STREAM_IDLE_TIMEOUT`). There is no overall timeout, because a
streamed completion can legitimately take minutes.

## Configuration flow

```
control plane ──(GET /api/internal/sync, deltas + periodic full resync)──► gateway
                                                                     │
                                         guard (ADR-0002) ◄──────────┤
                                                                     ▼
                                                   atomic swap of the snapshot
                                                                     │
                                                                     ▼
                                     encrypted snapshot on disk (cold start)
```

The contract is `api/sync/v2/sync-response.schema.json` (ADR-0003).

## Reference topology

- At least three gateway replicas spread over three zones, behind a regional L7
  load balancer health-checking `/readyz`.
- Capacity planned so two zones carry peak traffic below ~70% utilisation.
- Rolling deploys with no unavailable replicas, and a termination grace period
  longer than `STRATUM_DRAIN_DELAY + STRATUM_SHUTDOWN_TIMEOUT`.
- Control plane: two or more stateless replicas, PostgreSQL with a synchronous
  standby.
- Alerts on SLO burn rate and on `stratum_snapshot_age_seconds`.

This topology is part of the open-source edition (ADR-0006). The Helm chart in
`deploy/helm/stratum-gateway` implements it for the gateway.
